# Linked List in C

This repository contains my DSA practice programs on Linked Lists using C.

I have implemented three types of Linked Lists to understand how nodes, pointers and different operations work.

## Types of Linked Lists

1. **Singly Linked List (SLL)**
2. **Circular Linked List (CLL)**
3. **Doubly Linked List (DLL)**

## Files

- `singly_linked_list.c` – Singly Linked List
- `circular_linked_list.c` – Circular Linked List
- `doubly_linked_list.c` – Doubly Linked List

## Operations

The programs include:

- Creation of 3 nodes
- Traversal
- Insertion at beginning
- Insertion at end
- Deletion at beginning
- Deletion at end
- Insertion in the middle
- Deletion from the middle
- Searching an element
- Reversing a linked list (SLL)

DLL also includes forward and backward traversal.

## How to Run

Compile and run the programs using GCC.

**Singly Linked List**
```bash
gcc singly_linked_list.c -o singly
./singly
```

**Circular Linked List**
```bash
gcc circular_linked_list.c -o circular
./circular
```

**Doubly Linked List**
```bash
gcc doubly_linked_list.c -o doubly
./doubly
```
